# Cxc (Cuentas por cobrar).
El paquete CXC (Cuentas por cobrar) de V12 es el módulo encargado de la gestión de cuentas por cobrar de clientes y los documentos relacionados, funcionando como el núcleo para controlar los ingresos pendientes y garantizar la trazabilidad financiera dentro del ERP. Su propósito es centralizar la administración de facturas, pagos y saldos, integrándose con otros módulos para mantener la coherencia contable y financiera.
